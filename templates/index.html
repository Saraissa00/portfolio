NetGuard — Protocol Security Auditor

Cybersecurity / Networking

A pure-Python DNS hijacking detector that tells you, in one scan, whether your network is lying to you.

Objective

DNS hijacking and man-in-the-middle attacks silently redirect traffic before a user ever notices. The tool answers one question: has this network's DNS resolver been compromised?

How it works
  • Builds raw DNS query packets from scratch using Python's struct module — no external DNS library.
  • Sends parallel UDP queries to the local resolver and to Google's trusted public DNS (8.8.8.8).
  • Compares responses across four authoritative domains (iana.org, internic.net, ietf.org, ripe.net) and flags a mismatch outside the same /24 subnet as hijacking.
Stack

Python 3 (raw sockets, struct) · Flask web dashboard · CLI · zero external dependencies

Outcome

Delivers a clear SECURE / DANGER verdict via both a CLI and a web dashboard. Roadmap includes ML-based anomaly detection and DNSSEC integration.

HR Employee Attrition Predictor

Machine Learning

An MLP neural network that forecasts whether an employee is about to quit, with a from-scratch backpropagation module underneath it.

Objective

HR teams often spot flight-risk employees too late. The goal: turn satisfaction score, tenure, workload, and promotion history into an instant, explainable turnover forecast.

Key features
  • Trained an MLPClassifier (9 inputs → 6 → 5 hidden neurons → 1 output) on 14,999 real employee records, split 70/30 for train/test.
  • Three-stage pipeline: python1.py trains and pickles the model, use_the_brain.py loads it for instant inference, Frontend.py serves a Gradio web UI for HR staff.
  • A separate backprop_python2.py implements forward pass, loss, and weight updates in raw NumPy — no ML library — solving XOR to demonstrate the underlying math.
Stack

Python · scikit-learn · pandas / NumPy · joblib · Gradio

Results

96.84% test accuracy on a held-out 30% split of 14,999 employee records.
